# 更新賃料検討アプリ

募集条件の比較と、更新・転居の費用差から更新賃料を検討するツール。
仕様は [`docs/spec.md`](docs/spec.md) を正とする。

## 起動

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

動作確認用の案件を1件作る場合:

```bash
pnpm seed
```

費用条件は仕様書 §5「基本の確認例」に合わせてあり、結果画面で24ヶ月同額・25ヶ月逆転が確認できる。

## 確認

```bash
pnpm test         # 仕様書 §8 の受入確認12件を含む
pnpm typecheck
```

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/core/` | 計算のみ。画面にも保存にも依存しない純粋な処理 |
| `src/core/__tests__/acceptance.test.ts` | 仕様書 §8 の受入確認12件 |
| `src/lib/` | 保存（案件1件＝1JSONファイル）、Zodによる検証、結果の組み立て |
| `src/app/`, `src/components/` | 画面 |
| `data/cases/` | 案件の保存先（gitignore 済み） |

計算を `src/core/` に隔離しているのは、仕様書 §9 の
「同じ入力とルール版では同じ数値になる構成とする」を機械で検証できるようにするため。

## v0.1 の範囲

- 募集図面の読み取りは未実装。物件情報はすべて手入力
- 全件を居住用として扱い、**入力額はすべて税込の実支払額**
- 間取り・税区分は持たない
- 資料出力は印刷用レイアウト（ブラウザの「印刷 → PDF として保存」）
- 認証・共有なし。担当者1人がローカルで起動する前提

判定閾値（±2.5% / ±20% / 最低8件）は実務感覚による仮値で、画面から変更できる。
確定していない項目は `docs/spec.md` §9 に一覧がある。
