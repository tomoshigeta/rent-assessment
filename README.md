# 更新賃料検討アプリ

賃貸住宅の更新時に、**いくらで提示すれば貸主と借主の双方が成立するか**を検討する道具。

周辺の募集事例から対象物件の査定賃料を求め、そこに掛ける**掛け目 r の幅**を出す。
推奨額は出さない。幅の中から選ぶのは貸主の判断。

仕様は [`docs/spec.md`](docs/spec.md) を正とする。
**置いている仮定は第2章にまとめてある。使う前に必ず読むこと。**

## 使い方

```bash
pnpm install
pnpm dev            # http://localhost:3000
```

1. `public/更新賃料検討_入力シート.xlsx` をダウンロードし、募集図面から転記する
2. アプリでそのファイルを選ぶ
3. 原状回復費用と空室期間を入れる
4. r の幅と逆転月が出る。提示額を入れると、その額がどこに乗るかが分かる
5. 貸主用・借主用の資料を印刷（ブラウザの「印刷 → PDFとして保存」）

動作確認用に、実際の募集図面6件（麻布十番エリア・2026年9月）を記入した
`public/更新賃料検討_入力シート_記入例_麻布十番.xlsx` を同梱している。

## 計算

```
査定賃料 A = 比較事例の㎡単価の中央値 × 対象物件の面積   （手入力で上書き可）

借主上限 = 現在賃料 × (24 + 5) / (24 + 1.25) = 現在賃料 × 1.1485
貸主下限 = (A × (24 − 空室月数) − 原状回復費用) / 25.25
逆転月   = (5 × 現在賃料 − 1.25 × 提示額) / (提示額 − 現在賃料)
```

**借主上限は査定賃料に依存しない。** 更新後賃料が現在賃料の約14.9%増を超えると、
借主は転居したほうが得になる。

## 確認

```bash
pnpm test           # 79件
pnpm typecheck
pnpm template       # 入力シートのテンプレートを再生成（openpyxl が必要）
```

## 構成

| 場所 | 役割 |
| --- | --- |
| `src/core/v1/assumptions.ts` | **置いた仮定の全部**。根拠と実データとの差をコメントに書いてある |
| `src/core/v1/model.ts` | 借主上限・貸主下限・逆転月 |
| `src/core/v1/assess.ts` | 査定賃料と入力の検証 |
| `src/excel/columns.json` | 入力シートの列定義。テンプレート生成と取り込みの唯一の正 |
| `src/core/legacy/` | Ver2 用。月次キャッシュフローと旧受入確認12件。**Ver1 の計算はここを通らない** |

## Ver1 が扱わないもの

PDFからの抽出（アプリの外でやる）／広告費・AD／新規礼金／転居費用の費目別入力／
比較期間の可変化／築年・階・向きの補正／面積基準の区別／間取り

理由と影響は [`docs/spec.md`](docs/spec.md) 第7章にある。
