# 更新賃料検討アプリ 仕様書 v0.2

募集図面、対象物件の情報、更新時の希望賃料を入力し、周辺募集との比較結果と更新・転居の費用差を確認する。
貸主が提示額を選ぶと、借主への説明資料と貸主用の収支比較資料を作成する。

費用比較は24ヶ月を初期値とし、比較期間を変更できる。総負担が同額になる時点と、更新・転居のどちらが安いかが
変わる時期を表示する。

本書の妥当性は周辺募集条件との比較上の評価を指す。成約確率や募集期間の予測は初版の対象外とする。

---

## 0 v0.1 の範囲と、v0.1 で置いた前提

初版（v0.1）は **費用比較の計算と結果表示** を完成させることを目的とし、募集図面の読み取りは実装しない。
物件情報はすべて手入力で登録する。

| 前提 | 内容 | 影響する章 |
| --- | --- | --- |
| 用途 | **全件を居住用とする。** 事務所用は v0.1 の対象外 | §1, §2, §3 |
| 税 | **入力額はすべて税込の実支払額**とし、アプリは税率も税区分も持たない | §1, §3 |
| 図面読み取り | 実装しない。§1 の抽出項目は手入力欄として持つ | §1, §2 |
| 間取り | **項目自体を持たない**。面積で代替する | §1, §2, §7 |
| 利用形態 | 担当者1人がローカルで起動する。認証・共有は行わない | §9 |
| 資料出力 | 印刷用レイアウトを画面に表示し、ブラウザの「印刷 → PDF として保存」で出力する | §7 |
| 条件差の補正 | **行わない。** 築年数・駅距離等での絞り込みは利用者が事前に行う | §2 |
| 面積 | **基準を区別しない。** 専有・契約・壁芯を同じ「面積」として扱う | §1 |
| 広告費 | **持たない。** 貸主の入替コストは K = L に固定する | §6 |

v0.1 で持たない項目でも、後から読み取り機能を足したときにデータを作り直さずに済むよう、
保存形式には **原資料メタ（元ファイル・ページ・原文・資料日）と値の状態（読取値／確認済み／仮定値／不明）** を
最初から用意する。入力欄には出さない。

### v0.1 の入力項目

§1 の抽出項目のうち、**間取りと税区分を除く全項目**を対象物件・比較物件の双方で手入力する。

## 1 対象物件と比較物件の入力

| 項目 | 保存する内容 |
| --- | --- |
| 賃料・管理費 | それぞれの金額。**税込の実支払額**として入力する |
| 所在地 | 住所。建物名・部屋番号も保存する |
| 駅・徒歩分数 | 記載された駅と徒歩分数の組。複数駅を保持する |
| 面積 | 専有面積。原表記を残し、㎡に統一する |
| 築年数 | 竣工年月があれば保存し、評価時点の築年数を求める。直接入力も可 |
| 階数 | 対象階。総階数が記載されていれば別に保存する |
| 初期費用 | 敷金・保証金・礼金・償却・仲介料・保証料などを項目別に保存する |

費用計算に使う補助項目として、更新料、契約期間、フリーレント、入居可能時期を保持する。
**未記載項目はゼロに置き換えない**（§8-12）。設備は抽出・評価対象に含めない。

対象物件には上記に加えて、現在の賃料・管理費、希望する賃料・管理費、更新予定日、更新料の計算方法、
今後の費用発生時期を登録する。

### 金額の指定方法

金額は次の3つのいずれかで保持する。

- **確定額** — 円で確定している
- **倍率** — 「賃料の1ヶ月分」のように基準額へ連動する。基準額（家賃本体／家賃＋管理費）と倍率を保存し、
  提示額を変更したら再計算する（§4）
- **不明** — 記載がない。計算上は0として扱うが、**結果は参考値として扱い、不明項目を必ず表示する**

## 2 比較物件の選択と判定

### 比較対象の優先順位

希望賃料を比較物件の抽出条件に使わない。同じ建物で面積等が近い物件、同じ駅・徒歩圏で条件が近い物件の順に
比較する。隣接駅の物件は、生活・利用条件を代替できる場合に転居候補として扱う。

初版は **駅、徒歩、面積、築年数、階数** による絞り込みを優先する。条件差の大きい事例は参考扱いとし、
根拠のない金額補正を加えない。

比較物件は **採用 / 参考 / 除外** に分け、採用・除外の理由を残す。基準賃料には採用事例のみを使う。

### 必須項目の欠落

用途・賃料・管理費条件・所在地・面積のいずれかが欠けた事例は、**採用としていても基準賃料の集計から外し**、
その旨を判定理由に残す。

### 基準賃料

採用事例の **家賃＋管理費の月額総額** の中央値を基準賃料とする。
管理費の切り分けは募集主によって幅があり、家賃本体だけでは比較がぶれるため、総額を基準にする。
家賃本体の中央値も併記する。

中央値は、事例数が偶数のとき **中央2件の平均を円未満四捨五入** する。

**比較事例の絞り込みは利用者が行う。** 築年数・駅距離・面積などで比較に適う物件を利用者が選び、
その結果を登録する。アプリは登録された採用事例をそのまま集計し、**条件差による補正は一切行わない**
（v0.1 の方針。§0 参照）。

> **未決**: 総額を基準にする判断は実装時に置いた前提であり、実データで再確認する。
> 補正を自動化するかどうかは次版で検討する。

### 判定

判定の入力は乖離率 = (希望額の月額総額 ÷ 基準賃料 − 1) × 100 とする。

| 判定 | 条件 | 表示と次の操作 |
| --- | --- | --- |
| 妥当 | 乖離率が ±2.5% 以内 | 希望額を支持する比較材料を示し、その金額で資料を作成できる |
| 見直し推奨 | 乖離率が ±2.5% 超 ±20% 以内 | 割高・割安の理由と推奨額・検討範囲を表示する |
| 見直し推奨（要確認） | 乖離率が ±20% 超 | 強い警告として表示し、根拠の確認を促す |
| 資料不足 | 採用事例が **5件未満** | 足りない項目や比較条件を示す。基準賃料は参考値として表示し、判定は下さない |

割高側と割安側で幅は変えない。

価格判定は周辺募集との比較で行い、**転居費用による上限だけで「妥当」に変更しない**。

乖離率で判定するのは **対象物件の希望額だけ** である。比較事例が ±2.5% の帯に入るかどうかは
判定に関係しない。比較事例は中央値を決めるための集合であって、判定対象ではない。

> **未決**: ±2.5% / ±20% はいずれも実務感覚による仮値である。設定画面から変更でき、
> 実際の募集図面と試算結果を確認して確定する。最低件数は実図面での検証を経て5件に確定した。

## 3 費用比較の設定と項目

| 設定 | 仕様 |
| --- | --- |
| 比較期間 | 初期値24ヶ月。1〜120ヶ月の整数入力と 24・36・48ヶ月の選択ボタン |
| 逆転時期の探索 | 0〜120ヶ月。選択した比較期間より後の逆転も「選択期間外」として明示する |
| 比較する選択肢 | 据え置きで更新／希望額で更新／貸主が選んだ代案で更新／候補物件への転居 |
| 金額の扱い | **円単位の整数**で保存する。税込等の実際の支払額で比較する。税額控除や時間価値は算入しない |
| 端数処理 | **項目ごとに円単位へ確定してから集計する**。既定は四捨五入。案件単位で切上／切捨へ変更できる |
| 不明な費用 | 不明のまま保存する。仮定を置いた場合は仮定値であることを明記する |

表示用の万円換算・丸め値を次の計算に使わない。

### 費用の分類

| 分類 | 例 | 計算方法 |
| --- | --- | --- |
| 毎月の費用 | 家賃、管理費、月額保証料 | 1ヶ月目から、発生する月ごとに加算する |
| 一時的な費用 | 礼金、仲介料、引っ越し代 | 発生月を指定して加算する。開始時費用は0ヶ月目 |
| 定期的な費用 | 更新料、保証更新料、保険料 | 金額または倍率と発生時期・周期を登録する |
| 割引・返戻 | フリーレント、返戻金 | 対象項目と適用月を指定して控除する |
| 返還される預け金 | 敷金・保証金の返還予定部分 | **費用総額には含めず**、必要資金と返還予定を別表示する |

初期費用は合計額だけでなく内訳を保持する。「返還される預け金」と「返還されない償却等」を分け、
保証金全額を費用化しない。

既に支払った礼金等は今後の比較に再計上しない。原状回復費は、どちらの選択肢でも将来発生する部分を
一方だけに加えない。

## 4 月ごとの累計費用の計算

### 時間軸と発生月

比較開始日は更新後の賃料が適用される日とする。同じ時点で転居するシナリオを基本とする。
**開始時の一時費用を0ヶ月目、以後の家賃を1ヶ月目から計上する。**

24ヶ月の比較は開始から24ヶ月間を対象とする。24ヶ月を経過した時点で次の期間に入るための更新料は
**25ヶ月目**に計上し、24ヶ月終了時点の比較には含めない。

契約期間 C ヶ月の更新料の発生月は、開始時（今回の更新料）を含めるなら `0`、
以後 `1 + k·C`（k = 1, 2, …）とする。C = 24 なら **0, 25, 49, 73, 97** となる。
転居シナリオは新規契約のため開始時を含めず、最初の更新料は25ヶ月目になる。

### 累計費用の式

各シナリオ s について、開始時費用を `F`、m ヶ月目の月額費用を `M`、その月の追加費用を `E`、
割引・返戻を `D` とする。

```
C_s(0) = F_s
C_s(n) = C_s(n−1) + M_s(n) + E_s(n) − D_s(n)
A_s(H) = C_s(H) / H
```

`H` は比較月数、`A` は月額換算した負担額。開始時費用と毎月の費用を一度ずつ計上し、
支払基準を全シナリオで統一する。

### 重複計上を防ぐ処理

- **前家賃** — 契約時に払う前家賃は、その家賃が対応する月に一度だけ計上する。
  累計費用には加算せず、**契約時必要資金にだけ支払時点の金額として反映する**。
- **フリーレント** — 家賃のみ免除か管理費も免除かを保持し、対象月・対象項目だけを控除する。
- **倍率費用** — 基準額と倍率を保存し、提示額の変更時に再計算する。
- **預け金** — 預入・返還は費用と別の資金移動として保持する。
  償却・敷引として費用計上した額を再加算しない。
- **期間末** — 期間末に全シナリオが退去するとは自動で仮定しない。
  期間末精算を含める場合は両案で条件をそろえる。

### 契約時必要資金

累計費用とは別に集計する。

```
必要資金 = 0ヶ月目の費用（償却行を除く） + 0ヶ月目に預け入れる預け金の総額 + 前家賃
```

償却は預入総額の内数なので、預け金と二重に数えない。

## 5 総負担が逆転する時期の表示

更新シナリオ s と各転居候補 j について、同じ月数の累計費用の差を求める。

```
Δ_j(n) = C_j(n) − C_s(n)
```

**差が正なら更新の方が安く、負なら転居の方が安い。ゼロは同額**とする。判定は円単位の累計額で行う。

| 結果 | 表示方法 |
| --- | --- |
| 同額になる月 | 例「24ヶ月で同額」。同額と優劣の逆転を区別する |
| 最初の逆転 | 例「25ヶ月目の累計から転居が割安」。方向と月数を表示する |
| 更新料等による再逆転 | 探索期間内の全ての逆転を保持し、それぞれが割安な月の区間を表示する |
| 途中で同額を挟む | 同額期間の前後で優劣が変われば逆転。**同じ優劣に戻る場合は「同額時点あり」と表示する** |
| 逆転しない場合 | 「120ヶ月以内に逆転なし」など探索範囲を付ける。当初から転居が安い場合も区別する |
| 必要な費用が不明 | 不明の影響を示し、明示した仮定による参考計算とする |

0〜120ヶ月の各月を計算し、符号が変わる箇所とゼロの区間を抽出する。
**日数への補間は行わず「何ヶ月目に逆転」と表示する。**
各候補は開始時点からその物件を利用する独立したシナリオとする。

累計費用のグラフと月別明細を表示し、更新料・割引等の発生月を示す。
探索期間の延長を将来の賃料予測と扱わず、登録された条件が続く場合の計算として示す。

### 基本の確認例

更新は月額22万円・開始時費用20万円、転居は月額21万円・開始時費用44万円。途中の更新料等はない。

| 経過月数 | 更新の累計 | 転居の累計 | 結果 |
| --- | --- | --- | --- |
| 12ヶ月 | 284万円 | 296万円 | 更新が12万円安い |
| 24ヶ月 | 548万円 | 548万円 | 同額 |
| 25ヶ月 | 570万円 | 569万円 | 転居が1万円安い |
| 36ヶ月 | 812万円 | 800万円 | 転居が12万円安い |

## 6 更新賃料の上下限と貸主の収支

### 借主側の上限目安

利用条件が比較可能な転居候補ごとに、更新と転居の累計費用が等しくなる更新賃料を求める。
すべて固定額なら次式となる。

```
U_j = p + (F_j − F_s) / H
```

`p` は転居先の月額、`F_s` は更新時費用、`F_j` は転居時費用。

ただし **更新料が「賃料の1ヶ月分」のように賃料へ連動する場合、この式では解けない**。
実装は月次計算に対する二分探索で、`C_更新(H; x) ≤ C_転居(H)` を満たす最大の家賃 `x` を求める。
固定条件のときは上式と一致する。

複数の現実的な転居候補があれば、**各候補の上限のうち最も低い額**を表示する。
管理費を含む月額から上限を計算した場合は、管理費を差し引いた家賃本体も併記する。

### 貸主側の下限目安

同じ H ヶ月について、更新継続時の収支と退去後の再募集時の収支が等しくなる月額収入を求める。
再募集月額を `q`、無収入の空室月数を `d` とする。

```
L = q · max(H − d, 0) / (H + 1)
```

入替に伴う追加負担の差額 `K` は `K = L` と置いており、**広告費等の入力欄は設けない**。
`max(H − d, 0)` により、空室が比較期間全体に及ぶ場合も入居後月数が負にならない。

再募集を選んだ場合の比較期間内の収入合計 `q · max(H − d, 0)` を併記する。

**例**: H = 24、q = 21万円、d = 2ヶ月なら、再募集の収入合計は 462万円、下限目安は月額 184,800円。

### 収支の比較と結果の扱い

貸主には据え置き、希望額、選択した代案、退去後再募集の収支を並べる。
再募集賃料は希望する更新賃料と別入力にし、空室期間を変更して再計算できるようにする。

上下限は費用上の条件付きの損益分岐点として、周辺比較の基準賃料と並べる。
**下限は譲歩余地の内部検討に使い、上下限の中間を自動的な推奨賃料にしない。**
下限が上限を超える場合は、設定した条件で双方の採算が一致しないことを示す。

## 7 操作画面と説明資料の出力

### 画面構成（v0.1 は3画面）

| 画面 | 主な操作・表示 |
| --- | --- |
| 案件登録 | 対象物件、現在の条件、希望額、更新予定日を入力する |
| 比較設定 | 比較物件を採用・参考・除外に分け、費用・比較期間・再募集の仮定を設定する |
| 結果確認 | 基準賃料、希望額の判定、上下限、期間別の累計負担、逆転時期、貸主収支を表示する |

§0 のとおり「読取確認」は図面読み取りを実装しないため置かない。
「資料作成」は結果確認から印刷用レイアウトを開く形にする。

### 借主向け説明資料

名称は「更新賃料のご提案」。A4・2ページを基本とする。

- 1ページ目 — 対象物件、現在と提案後の家賃・管理費、適用予定日、提案の理由、周辺募集の比較表
- 比較表の列は対象物件と比較A・B・C等、**行は用途、所在地、駅・徒歩、面積、築年数、階数、
  家賃・管理費、主な初期費用**（間取りは §0 のとおり持たない）
- 2ページ目 — 比較月数、更新・転居の総負担、同額・逆転時期、返還される預け金の別表示、
  費用の仮定、資料日・出典

### 貸主向け検討資料

名称は「更新賃料の検討結果」。希望額への判定と理由、周辺比較の基準額、借主側の上限と貸主側の下限、
据え置き・希望額・代案・再募集の収支を載せる。空室月数・費用の仮定、反対材料、保留項目も記載する。

### 出力と保存

両資料は同じ案件・計算結果から作成し、基準日、比較期間、採用事例、選択した提示額を固定して保存する。
条件を変えた場合は再計算し、新しい出力版として残す。

**借主用に貸主の収支や譲歩の下限を混在させない。** 資料の自動送付は行わず、貸主が確認して出力する。

## 9 未決事項と改訂方針

| 項目 | 現時点の案 | 次に決める内容 |
| --- | --- | --- |
| 比較物件の採用 | 利用者が絞り込む。アプリは補正しない | 補正の自動化を次版で検討するか |
| 基準賃料 | 採用事例の**家賃＋管理費**の中央値 | 総額基準の妥当性、重み付け、補正項目、価格帯 |
| 判定閾値 | ±2.5% / ±20%（対称）。最低5件は確定 | ±2.5% / ±20% の実データによる確定 |
| 費用の共通設定 | 居住用のみ | 未記載時に使う費用項目・初期値・入力の必須範囲 |
| 費用の発生基準 | 開始費0ヶ月目、次回更新料は 1+k·C ヶ月目 | 日割り対応、請求日と費用対象月が異なる場合の操作 |
| 説明資料 | 借主用はA4・2ページ、印刷経由でPDF | 掲載件数、書式、ロゴ、配色、サーバ側PDF生成の要否 |

| 広告費 | 持たない | 次版で貸主の入替コストに含めるか |

### 保存と再現性

入力値・仮定値、比較物件の採否、算定ルールの版、比較期間、費用発生月、出力日時を案件単位で保存する。
**同じ入力とルール版では同じ数値になる構成とする。**
そのため計算は `src/core/` に、画面・保存から独立した純粋な処理として置く。

AIは図面の読み取り・説明文の作成に使用し、金額と逆転時期は計算処理で求める。

## 改訂履歴

### v0.3（本書）

実際の募集図面6件（麻布十番エリア・2026年9月）で検証した結果の反映。

1. **最低事例数を 8件 → 5件** — 同一エリア・同一条件で8件を同時期に集めるのは現実的でないと確認した。
2. **判定対象を明記** — ±2.5% の帯で判定するのは対象物件の希望額だけであり、
   比較事例が帯に入るかは判定に無関係であることを §2 に明記した。
3. **条件差の補正を行わないことを確定** — 実図面では築年で ㎡単価が 4,064〜7,594円 に割れたが、
   補正の自動化はせず、**利用者が絞り込んでから登録する**方針とした（§0, §2）。
4. **面積の基準を区別しない** — 図面には専有面積・契約面積・使用部分面積（壁芯）が混在するが、
   実務でそこまで厳密に扱われないため、同じ「面積」として扱う（§0, §1）。
5. **広告費を持たないことを再確認** — 図面には AD・広告宣伝費・業務委託料の記載があるが、
   v0.1 では貸主の入替コストを K = L に固定したまま扱わない（§0, §6）。

### v0.2

初版（v0.1 仕様書）からの変更点。

1. **§6 貸主下限式を改訂** — `L = (q(H−d) − K)/H` を `L = q·max(H−d,0)/(H+1)` に置き換えた。
   `K = L` と置くことで K の入力が不要になる。広告費等の入力欄は設けない。
   これに伴い §6 の「空室期間・広告費等を変更して再計算できるようにする」から広告費を削除した。
2. **§8-11 の期待値を改訂** — 再募集比較収支 432万円 → 収入合計 462万円、下限月額 18万円 → 184,800円。
3. **§8-04 の期待結果を補足** — 24ヶ月にも同額時点があるが優劣は変わらない、という区別を明記した。
   旧版はこの点に触れておらず、「同額を検出したら逆転」と読める余地があった。
4. **税の扱いを確定** — v0.1 は全件居住用とし、入力額をすべて税込の実支払額と定義した。
   税区分フィールドは計算に使わない。
5. **間取りを削除** — §1 の抽出項目、§2 の絞り込み軸、§7 の比較表から外した。
6. **中央値の定義を追加** — 事例数が偶数のときは中央2件の平均を円未満四捨五入する。
7. **基準賃料の基準を明記** — 家賃＋管理費の月額総額の中央値とした（実装時に置いた前提。§9 に未決として残す）。
8. **判定閾値を明記** — ±2.5% / ±20% / 最低8件、割高・割安で対称。仮値である旨を併記。
9. **端数処理の既定を明記** — 項目ごと円単位で四捨五入。案件単位で切上／切捨に変更できる。
10. **更新料の発生月を式にした** — 開始時 `0` と `1 + k·C`。旧版は24ヶ月の例のみ記載していた。
11. **借主上限の求め方を明記** — 賃料連動費用があるため二分探索で求める。閉じた式は固定条件時の検算用。
12. **契約時必要資金の式を追加** — 償却と預け金の二重計上を避ける集計順を明記した。
13. **§7 の画面を v0.1 は3画面に** — 「読取確認」を置かず、「資料作成」を結果確認から開く。
